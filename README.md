# DayBox

桌面任務與便簽管理工具，基於 Electron 開發。

## 功能

- ✅ 任務管理（新增/編輯/刪除/完成）
- ✅ 分類篩選（工作/個人/學習/其他）
- ✅ 優先級管理（高/中/低）
- ✅ 搜尋、排序、狀態篩選
- ✅ 拖曳排序
- ✅ 便簽功能（多色卡片式便簽）
- ✅ 資料以 JSON 檔存於程式同目錄，可攜帶
- ✅ 溫暖配色主題

## 開發

```bash
# 安裝依賴
npm install

# 啟動開發模式
npm start

# 打包為可執行檔
npm run build
```

## 技術棧

- Electron
- HTML / CSS / JavaScript
